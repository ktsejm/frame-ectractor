# Frame Extractor

動画の最初と最後のフレームを抽出するブラウザツールです。  
複数の動画をつなぐ前処理として、各クリップのつなぎ目フレームを素早く確認・保存できます。

**→ [ツールを開く](https://ktsejm.github.io/frame-extractor/frame_extractor.html)**

## 概要

複数の短い動画をつなぐとき、各動画の「最後のフレーム」と「次の動画の最初のフレーム」を並べて確認する作業が必要になります。このツールはその前処理を半自動化します。

- 動画をアップロードすると、**先頭フレーム（first）と末尾フレーム（last）を自動抽出**
- **接続ペアタブ**で、前の動画の末尾と次の動画の先頭を並べて確認
- 抽出フレームを **1枚ずつ / ZIP一括** で保存
- **すべてブラウザ内で処理**。動画データはサーバーに送信されません

---

## 使い方

1. [ツールを開く](https://ktsejm.github.io/frame-extractor/frame_extractor.html)
2. 「タップして動画を選択」から動画ファイルを選ぶ（最大10本）
3. 画像品質を選択（JPEG標準 / JPEG高品質 / PNG）
4. 「処理する」を押す
5. **接続ペアタブ**でつなぎ目フレームを確認
6. 必要なフレームを個別保存、またはZIPで一括保存

## 対応ファイル形式

- **mp4**（H.264推奨）
- **mov**

> H.265 / HEVC など Safari がデコードできないコーデックは抽出失敗になる場合があります。

---

## 機能一覧

| 機能 | 内容 |
|---|---|
| フレーム抽出 | 各動画の先頭・末尾フレームを自動抽出 |
| 接続ペア表示 | clip N の末尾 → clip N+1 の先頭 を並べて表示 |
| 個別保存 | フレームを1枚ずつ JPEG / PNG で保存 |
| ZIP一括保存 | 全フレームをまとめて保存 |
| 画像品質選択 | JPEG 85% / JPEG 95% / PNG から選択 |
| ファイル名 | 日時 + ペア番号 + クリップ番号で自動命名 |
| ローカル処理 | サーバー不要・インターネット接続不要（ページ読み込み後） |

## ファイル命名規則

### ZIP一括保存
```
frames_20260405_1345_6clips.zip
```
`frames_{日付}_{時刻}_{本数}clips.zip`

### 接続ペアからの個別保存
```
20260405_1345_pair01_clip1-last.jpg
20260405_1345_pair01_clip2-first.jpg
```

### フレーム一覧からの個別保存
```
20260405_1345_clip01_first.jpg
20260405_1345_clip01_last.jpg
```

---

## 制限・注意事項

- 1回に処理できる動画は最大 **10本**
- 推奨動画長は **10秒前後**（長くても動作しますが、メモリ使用量が増えます）
- 大容量ファイル（1本あたり100MB超）を複数本処理するとメモリ不足になる場合があります
- フレーム抽出はブラウザの動画デコード機能を使用するため、端末性能に処理速度が依存します
